# 异常检测与区块链智能合约（预留）

## 扩展点

- 接口：`com.kewei.parts.module.anomaly.chain.AnomalyChainContractHook`
- 默认实现：`NoopAnomalyChainContractHook`（空操作，不改变现有行为）

在 `AnomalyServiceImpl` 中，以下时机会回调接口：

| 时机 | 方法 | `action` / 说明 |
|------|------|-----------------|
| 规则创建成功 | `afterRuleMutation(rule, "create")` | — |
| 规则更新成功 | `afterRuleMutation(rule, "update")` | — |
| 规则删除成功 | `afterRuleMutation(rule, "delete")` | 传入删除前快照 |
| 预警处理完成 | `afterAlertHandled(alert)` | 库中已更新后的实体 |

## 接入长安链等实现时建议

1. 新增实现类（例如 `ChainMakerAnomalyChainContractHook`），在其中调用 ChainMaker SDK、组装合约参数、异步上链，避免阻塞主事务。
2. 使用 `@Primary` 或 `@Profile("chain")` + 配置切换，替换默认 `Noop` 实现。
3. 失败策略：建议记录失败任务表或 MQ 重试，避免链上失败导致业务回滚（当前钩子在事务提交后调用更稳妥，如需可改为事务后事件）。

## 与前端

异常检测页面已改为请求真实 REST：`/api/anomaly/**`（经网关前缀与 `request` 的 `baseURL` 拼接）。规则类型与后端一致：`time` / `quality` / `logistics`。
