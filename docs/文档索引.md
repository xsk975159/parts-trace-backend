## 配置与脚本

- `src/main/resources/chainmaker/sdk_config.yml.example` → 本地复制为 `sdk_config.yml`（勿提交密钥）
- 存储模式：`application.yml` 中 `parts.trace.storage.chain-mode` / `object-mode`
- 长安链真实调用：`chainmaker.sdk.invoke-enabled`（环境变量 `CHAINMAKER_SDK_INVOKE_ENABLED`）

数据库初始化：`src/main/resources/db/init.sql`。
