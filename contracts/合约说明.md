# 长安链智能合约（本仓库可部署源码）

Go 语言合约位于 **`trace_anchor/`**，编译为 **WASM** 后，通过长安链 **cmc**、管理台或 CI 镜像部署（与节点版本一致，常见为 ChainMaker 2.3.x）。

## 目录

| 路径 | 说明 |
|------|------|
| `trace_anchor/main.go` | 存证锚点 + DID 下挂 VC 哈希 + 跨链摘要写入 |
| `trace_anchor/go.mod` | `contract-sdk-go/v2`，与节点/文档保持同大版本 |

## 合约方法（invoke method）

与后端 `ChainMakerSdkInvoker` / `ChainMakerChainStorageAdapter` 应对齐参数（`map[string][]byte`）：

| method | 参数 key | 说明 |
|--------|-----------|------|
| `save_anchor` | `business_type`, `business_id`, `data_hash` | 必填；可选 `object_cid`, `parts_did` |
| `append_vc` | `parts_did`, `vc_id`, `vc_hash` | 5.1：凭证 ID 与内容哈希挂在 DID 下（field=vcId） |
| `revoke_vc` | `parts_did`, `vc_id` | 将对应 vc 写入 `"0"` 表示撤销 |
| `receive_cross_anchor` | `source_chain_id`, `source_tx_hash`, `parts_did`, `data_hash` | 5.2 原型：主链接收从链摘要；可选 `object_cid` |

链上会 **EmitEvent**：`anchor_saved`、`vc_appended`、`cross_anchor_received`（便于网关订阅）。

## 编译与部署（概要）

1. 安装 **Go 1.18+**，在本目录执行：
   ```bash
   cd trace_anchor
   go mod download
   ```
2. 使用官方文档中的 **合约编译工具链**（TinyGo / 官方 Docker / `cmc` 参数以你所用刀具为准）生成 `.wasm`。
3. 使用 **Java SDK**（本仓库 `chainmaker-sdk-java`）或 **cmc** 做 `contract create` / `invoke`，合约名建议与 `application.yml` 中 `chainmaker.wasm-contract-name` 一致（默认占位 `trace_anchor`）。

> 具体命令行因各发行版手册略有差异，请以 [长安链文档](https://docs.chainmaker.org.cn/) 当前版本为准；本仓库提供 **可提交评审的合约源码**。

## 与 Java 后端对接

部署成功后，`chainmaker.sdk.invoke-enabled=true` 时：

- `ChainMakerSdkInvoker.invokeSaveAnchor` 调用 **`save_anchor`**
- `invokeAppendVc` 调用 **`append_vc`**
- `CrossChainRelayService`（跨链中继）调用主链 **`receive_cross_anchor`**

详细环境变量与模式切换见：`docs/装配与部署指南.md`。
